Simi的教學群島整理

四座自學網站，一張海圖。從積木出發，一路航向文字程式；想用圖形學代數的，走數學支線到 GGB 數學島。

01

Scratch 積木群島

工具：Scratch

3D 跳島網站，每座小島對應一類 Scratch 積木，一島一島認識積木分類。

對象
7 年級，還沒學過文字程式語言
重點
只用 Scratch，不混入其他語言
登島 → GitHub
ldjh-scratch-islands.vercel.app
02

App Inventor 教學島

工具：MIT App Inventor

用積木做出手機 App。站內有模擬的 App Inventor 工作區，可以直接看積木怎麼拼，也能下載 .aia 範例檔匯入練習。

對象
學過 Scratch、想做手機 App 的學生
特色
模擬工作區 + 可下載 .aia 檔
登島 → GitHub
ldjh-appinventor-islands.vercel.app
03

Python 教學島

工具：Python（瀏覽器內執行，Pyodide）

天空之城風格的浮空島，在瀏覽器裡直接寫、直接跑 Python，不用安裝任何軟體。

對象
任何想自學 Python 的人
特色
免安裝，打開網頁就能執行程式
登島 → GitHub
ldjh-python-islands.vercel.app

GGB 數學島

工具：GeoGebra

透過幾何作圖理解代數，讓學生自己動手操作 GeoGebra、自主學習。

對象
國中資優班學生
重點
以幾何學代數，自學為主
登島 → GitHub
