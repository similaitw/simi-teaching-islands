# Simi的教學群島基地站

## 👉 [點這裡進入網站](https://similaitw.github.io/simi-teaching-islands/)

**https://similaitw.github.io/simi-teaching-islands/**

所有教學島從這個基地站出航，分成四個海域：

| 海域 | 島嶼 | 工具 | 網站 |
|---|---|---|---|
| 積木區 | Scratch 積木群島 | Scratch | [ldjh-scratch-islands.vercel.app](https://ldjh-scratch-islands.vercel.app) |
| 積木區 | App Inventor 教學島 | App Inventor | [ldjh-appinventor-islands.vercel.app](https://ldjh-appinventor-islands.vercel.app) |
| 程式區 | Python 教學島 | Python | [ldjh-python-islands.vercel.app](https://ldjh-python-islands.vercel.app) |
| 進階區 | Arduino 機械星系 | Arduino（線上模擬） | [ldjh-arduino-islands.vercel.app](https://ldjh-arduino-islands.vercel.app) |
| 進階區 | GGB 數學島 | GeoGebra | [ldjh-ggb-math-island.vercel.app](https://ldjh-ggb-math-island.vercel.app) |
| 競賽區 | 算衍修仙錄：積木計算篇（宜蘭競賽版） | Blockly（同宜蘭競賽平台） | [ldjh-scratch-computation.vercel.app](https://ldjh-scratch-computation.vercel.app) |
| 競賽區 | 資訊科技競賽題目詳解（課堂用，需登入） | Blockly（同宜蘭競賽平台） | [ict-blockly-solutions.vercel.app](https://ict-blockly-solutions.vercel.app) |
